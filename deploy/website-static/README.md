# MEDORA static website package

This folder contains a deployable static website for the public web presence of MEDORA.

## Included
- `index.html` — single-file public landing page
- `vercel.json` — Vercel static hosting config
- `netlify.toml` — Netlify static hosting config
- `.nojekyll` — GitHub Pages compatibility marker

## Important
This package is intended for the **public website / brand presence**.
The operational MEDORA application remains the full-stack app in the repository root and requires its own Node + database deployment.
