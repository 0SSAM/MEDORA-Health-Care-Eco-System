# مدار — مساحة إدارة أعمال تجريبية

واجهة عربية RTL مبنية باستخدام Next.js App Router وPostgreSQL وDrizzle ORM. يحتوي المستودع الأصلي على قالب بداية ومسار `/api/health` فقط؛ تم الإبقاء على فحص الصحة وإضافة الوحدات التالية.

## المسارات

| المسار | الوظيفة |
|---|---|
| `/` و`/dashboard` | لوحة التحكم والمؤشرات والرسوم والجولة التعريفية |
| `/sales` | فواتير المبيعات |
| `/purchases` | طلبات الشراء |
| `/inventory` | المنتجات والمخزون |
| `/customers` | العملاء |
| `/suppliers` | الموردون |
| `/team` | أعضاء الفريق وأدوارهم الوصفية |
| `/reports` | عرض الأداء وتصدير سجلات الوحدات |
| `/settings` | معلومات مساحة العمل وتفضيلات العرض |
| `/help` | الإرشادات والأسئلة الشائعة |
| `/api/demo` | إنشاء جلسة العرض وقراءة وتعديل بياناتها |
| `/api/health` | فحص اتصال التطبيق بقاعدة البيانات |

الوحدات الست تدعم الإضافة والتعديل والحذف والبحث وتصفية الحالة وتحديد السجلات وتصدير CSV. البحث الشامل متاح بزر البحث أو Ctrl/⌘ + K. النوافذ تدعم Escape وحصر التنقل بلوحة المفاتيح.

## الحساب غير الإنتاجي

- الدخول تلقائي، بلا اسم مستخدم أو كلمة مرور.
- جلسة مستقلة مدتها ٢٤ ساعة لكل متصفح، بمعرّف UUID عشوائي داخل cookie من نوع HttpOnly وSameSite=Lax وSecure في الإنتاج.
- جدولان مخصصان `demo_sessions` و`demo_records`؛ جميع استعلامات السجلات مقيدة بمعرّف الجلسة من الخادم، وليس من مدخلات العميل.
- ٢٣ سجلًا توضيحيًا يُنسخ لكل جلسة. يُحظر تحديث أو حذف سجل من جلسة أخرى.
- إعادة الضبط تستعيد السجلات والإعدادات الخاصة بالجلسة فقط، داخل معاملة قاعدة بيانات.
- تنتهي صلاحية الوصول بعد ٢٤ ساعة؛ تُنظف الجلسات المنتهية عند إنشاء جلسات جديدة.
- لا توجد بوابة دفع أو إرسال بريد أو حسابات إنتاجية أو تنفيذ صلاحيات حقيقية لأعضاء الفريق. هذه بيئة عرض أعمال وليست نظام محاسبة إنتاجيًا.
- المؤشرات تتضمن أرصدة تاريخية توضيحية لشهر يونيو ٢٠٢٤، مع انعكاس تغييرات إجماليات المبيعات والمشتريات والعملاء. الرسم والاتجاهات ونشاط البداية أمثلة تجريبية. تغيير فترة الرسم يغير السلسلة التوضيحية، لا فترة المؤشرات الشهرية.
- تصدير CSV يحتوي على السجلات التفصيلية فقط، مع حماية من صيغ الجداول الإلكترونية. تغيير العملة يغير رمز العرض للسجلات ولا ينفذ تحويل أسعار صرف.
- الخط العربي مستضاف محليًا؛ لا تحتاج الواجهة إلى خدمات أو مفاتيح خارجية.

## التشغيل

اضبط `DATABASE_URL` في البيئة، وثبّت الاعتماديات، ثم طبّق الجداول باستخدام `npx drizzle-kit push`. استخدم `npm run dev` للتطوير. للإنتاج استخدم HTTPS لضمان إرسال ملف تعريف الارتباط الآمن.

## التحقق

1. `npx next typegen`
2. `npm exec tsc -- --noEmit --pretty false`
3. `npm run build`
4. شغّل المعاينة المُدارة.
5. `npx playwright install --with-deps chromium`
6. `npx playwright test`

الاختبارات تستخدم افتراضيًا `http://localhost:3000`، ويمكن ضبط `PLAYWRIGHT_BASE_URL` للاختبار عبر عنوان المعاينة. تشمل الاختبارات المسارات، وعزل الجلسات، والتحقق من المدخلات، وCRUD وإعادة الضبط، وتصدير الملفات، والتنقل على الهاتف.
