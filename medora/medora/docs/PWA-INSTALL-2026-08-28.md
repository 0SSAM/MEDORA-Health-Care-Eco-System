# PWA Installable — تثبيت ميدورا كتطبيق (بديل المثبِّتات)

**2026-08-28** — ميدورا أصبحت تطبيق ويب قابلاً للتثبيت (PWA) على جميع الأجهزة دون متاجر.

## ما أُضيف
| المكوّن | المسار |
|---|---|
| أيقونات التطبيق | `client/public/icons/medora-192.png`, `medora-512.png` |
| بيان التطبيق (Manifest) | `client/public/manifest.webmanifest` (RTL، لغة ar، ألوان ميدورا) |
| عامل الخدمة (Service Worker) | `client/public/sw.js` (تخزين مؤقت + عمل دون اتصال) |
| الربط | `client/index.html` + `client/src/main.tsx` (تسجيل SW عند الإقلاع) |

## طريقة التثبيت
- **أندرويد/كروم**: افتح الموقع → قائمة ⋮ → "تثبيت التطبيق" / Add to Home screen.
- **iOS (Safari)**: زر المشاركة ← "إضافة إلى الشاشة الرئيسية" (مدعوم عبر meta tags).
- **سطح المكتب**: أيقونة التثبيت في شريط العنوان (Chrome/Edge).

## لماذا PWA بدل exe/apk/ipa؟
- بيئة البناء لا تتضمن سلاسل أدوات Electron/Android SDK/Xcode.
- PWA يغطي: التثبيت من المتصفح، الإشعارات، العمل دون اتصال (SW)، وتحديث تلقائي — دون متاجر أو توقيع.
- المسار الأصلي (exe/apk/ipa) يبقى متاحًا عبر React Native / Electron خارج نطاق هذا المستودع.
