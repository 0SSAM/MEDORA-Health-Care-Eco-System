# Egyptian Medicine Register — Source-Safe Delivery Note

## Delivered artifact

The companion workbook is `egypt-medicine-register-source-safe-template.xlsx`. It is a structured template for future verified records, not a complete Egyptian medicine database.

## Coverage

The workbook includes fields for Arabic and English names, active ingredient, strength, dosage form, manufacturer, registration number and status, provenance URL, source publication date, verification timestamp, verification method, jurisdiction, and notes. It also includes a methodology sheet and a source-register sheet.

## Source register

The current primary source reviewed is the [Egyptian Drug Authority regulatory reference for pharmaceutical products](https://edaegypt.gov.eg/en/the-regulatory-reference-of-the-egyptian-drug-authority-eda/regulatory-guidelines/ca-of-pharmaceutical-products/). The page provides regulatory guidance, but it is not a complete machine-readable public medicine register.

## Limitations and safe-use rule

No medicine rows were populated because a reproducible official EDA bulk register was not available during this build. Commercial or inferred lists must not be imported as official records. Each future row must be supported by a reproducible primary source, effective or publication date where applicable, a verification timestamp, and a documented verification method. The clinical-trials archive remains intentionally skipped according to the user’s instruction.
