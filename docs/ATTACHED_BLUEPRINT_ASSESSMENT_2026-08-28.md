## نطاق التعديل المقبول

سيُوسّع اختبار Playwright العام الموجود إلى جهاز هاتف محدد. وسيبقى الاختبار غير موثق ومحصوراً في اتجاه اللغة وسلامة المسارات العامة وحالة الوصول الآمنة. لا هجرات، ولا بيانات تجريبية، ولا تسجيل دخول، ولا معاملات صحية أو مالية أو تأمينية أو رسائل أو أجهزة حية.

## خريطة الحدود الأمنية

| حد MEDORA | أثر التوسعة المقبولة | قرار السلامة |
| --- | --- | --- |
| المؤسسة والفرع والاختصاص | لا يرسل الاختبار هوية أو معرف نطاق، ولا يدخل مساحة تشغيل موثقة. | لا تغيير في التحقق الخادمي أو في عزل البيانات. |
| المصادقة وNDA | يتحقق الاختبار من أن المسارات العامة لا تنتج صفحة فارغة أو خطأ غير معالج؛ لا يسجل دخولاً ولا يقبل NDA. | تبقى بوابات الدخول وNDA كما هي دون تجاوز. |
| التدقيق | لا ينفذ الاختبار طفرات أو تصديراً أو نسخاً أو طباعة أو اتصالات خارجية. | لا ينشأ حدث تدقيق صناعي ولا تتأثر السجلات. |
| الهاتف وRTL | يستخدم Playwright ملف هاتف قياسياً لنفس اختبارات لغة الواجهة وحالة الوصول الآمنة. | توسيع تحقق العرض فقط، بلا صلاحيات أو بيانات إضافية. |

## حدود مقصودة

لا يُنشأ ملف Prisma أو `package-lock.json` أو برنامج Bash مولّد أو مجلد تقارير جديد. يعتمد CI القائم على تثبيت Playwright عند التشغيل ويحتفظ بالتقارير الناتجة عند الفشل وفق التهيئة الحالية. أي توسيع مستقبلي لاختبارات وظائف محمية يتطلب حساباً مصرحاً وبيانات معزولة وموافقة نطاق منفصلة.

### أدلة التحسين المطبق

يغطي اختبار `server/_core/readiness.contract.test.ts` الاستجابة الثابتة والحدود السلبية: المسار مجهول، ويمنع التخزين المؤقت، ولا يحتوي تنفيذه على اعتماد قاعدة بيانات أو بيئة أو سياق جلسة أو مصادقة أو نطاق أو أسرار. وقد مر فحص النوع واختبار العقد وVitest الكامل وبناء الإنتاج وتدقيق تبعيات الإنتاج و`git diff --check`، كما ظهر `/` و`/healthz` بصورة سليمة على سطح المكتب والهاتف. لم تتغير البيانات أو المخطط أو التكاملات أو إجراءات صحية/مالية/تأمينية/حكومية أو رسائل أو أجهزة حية.
