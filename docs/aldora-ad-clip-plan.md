## Vertical cut

The 90-second vertical version preserves the opening tension, pharmacy/POS, traceability, hospital, management/AI, security, and final brand resolve. It uses tighter close-ups, central-safe compositions, and large negative space around the subject for platform UI chrome. Audience-specific short edits will use one value proposition each and retain the same final phrase.

## Narration direction

The male Arabic narrator is authoritative, warm, articulate, and measured, with short pauses after each audience transition. No clip should require rushed speech; the visual system carries detail while the voice carries meaning.
