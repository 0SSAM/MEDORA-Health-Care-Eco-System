## قائمة قبول إلزامية

- [ ] يذكر MEDORA Health Care Eco System فقط، ولا يظهر اسم قديم في الملف أو النص أو بطاقة النهاية.
- [ ] كل لقطة فعل حي أو حركة كاميرا/واجهة مبررة؛ لا slideshow ولا لقطة ثابتة طويلة.
- [ ] الشخصيات والبيئات ثابتة الهوية، مهنية ومحايدة، ولا أزياء خليجية أو قوالب نمطية.
- [ ] لم تُعرض بيانات شخصية أو مرضية أو مريض حقيقي أو معرف دواء حقيقي.
- [ ] GAHAR والفاتورة الإلكترونية يظهران كجاهزية ومسار مضبوط، لا اعتماد رسمي مختلق.
- [ ] الذكاء الاصطناعي يقدم توصية، مع موافقة أو رفض بشري واضح قبل تنفيذ حساس.
- [ ] الترجمة العربية مقروءة ضمن المنطقة الآمنة للمنصة ومراجعة إملائياً.
- [ ] الشعار الرسمي يُركّب في post-production ولا يستبدل بشعار مولّد.
- [ ] النسخة الرأسية أعيد تكوينها لقطة بلقطة ولم تُقص تلقائياً من النسخة الأفقية.
