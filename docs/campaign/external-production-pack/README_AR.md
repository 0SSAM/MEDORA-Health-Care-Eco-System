# حزمة الإنتاج الخارجي — MEDORA Health Care Eco System

هذه الحزمة تسلّم لفريق إنتاج أو منصة فيديو خارجية كل المواد المكتوبة والمرجعية اللازمة لإكمال حملة MEDORA السينمائية الواقعية: النسخة الأفقية الرئيسية (150 ثانية)، والنسخة الرأسية (90 ثانية)، والمقاطع القصيرة حسب الجمهور.

> **قفل الهوية:** الاسم المعتمد والوحيد هو **MEDORA Health Care Eco System**. لا تستخدم Aldora أو أي اسم سابق في الصوت، أو النصوص، أو البيانات الوصفية، أو الشعار، أو بطاقة النهاية.

## ما هو متاح فعلياً في هذه النسخة

يشمل الأرشيف المرجع البصري السينمائي، مسارات تعليق صوتي عربية للنسختين، مقطوعة أصلية، ولقطات فيديو تجريبية متاحة. لا يدّعي أن نسخة الفيلم النهائي بطول 150 ثانية أو 90 ثانية مركّبة داخل الأرشيف؛ إذ توقّف توليد اللقطات الإضافية عند حد الفيديو اليومي في منصة التوليد. بقية اللقطات موصوفة بالكامل ومهيأة للتوليد أو التصوير الخارجي.

## قواعد لا تقبل التغيير

- فيلم واقعي حي بحركة كاميرا وأفعال بشرية واضحة؛ **ليس** عرض صور متتابعة أو مونتاج صور ثابتة.
- شخصيات بالغة مهنية محايدة دولياً؛ لا أزياء خليجية ولا قوالب ثقافية نمطية.
- لا بيانات مرضى حقيقية، ولا أسماء أدوية حقيقية، ولا شهادات عملاء أو تقييمات مختلقة.
- أظهر GAHAR والفاتورة الإلكترونية كـ **جاهزية ومسار عمل مضبوط**، لا كاعتماد حكومي أو شهادة رسمية غير مثبتة.
- الذكاء الاصطناعي يقدم توصية قابلة للمراجعة؛ لا قرار حساس ذاتي التنفيذ.
- استخدم شعار MEDORA المعتمد الذي يورده العميل في ما بعد الإنتاج؛ لا تطلب من نموذج توليد الصور ابتكار شعار بديل.

## ترتيب التنفيذ الخارجي المقترح

1. اعتماد الوجوه والبيئات من المرجع البصري ولقطة الاختبار المتاحة.
2. توليد/تصوير لقطات الـShot List مع عدم تغيير الشخصيات أو لغة الإضاءة أو واجهة MEDORA.
3. تسجيل التعليق وفق النص المعتمد أو استخدام ملفات WAV المتاحة بعد مراجعة النطق.
4. تركيب النسخة 16:9 أولاً، ثم **إعادة تكوين** النسخة 9:16؛ لا تقص النسخة الأفقية قصاً آلياً.
5. وضع الترجمة العربية، الشعار المعتمد، ومراجعة الامتثال ثم التصدير وفق `06_delivery/export-specifications.md`.
