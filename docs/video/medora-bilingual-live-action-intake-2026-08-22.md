## Proposed Default Pending Final Scope Confirmation

To preserve attention and avoid repeating limited footage, the working default is a **55–65 second 16:9 master per language edition**. Each uses the same action cut but a separately timed male narration, opposing-language burned-in subtitle track, fixed MEDORA logo, original 118–124 BPM electronic/percussive instrumental, and a final MEDORA end card. This is a production assumption, not a completed export.
