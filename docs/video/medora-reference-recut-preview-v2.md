# MEDORA Reference-Recut Preview v2

## Status and purpose

This is a **12.4-second, 16:9, silent motion preview**. It is a new edit of two short visual excerpts from the user-supplied 150-second file, not a new AI-generated film and not the 150-second campaign master. It was created only to demonstrate the approved direction: human-led pharmacy operations, traceability as a visual motif, and accountable human review.
