# سياسة حماية التقاط الشاشة والتسجيل على الهاتف

## نطاق السياسة

تطبق واجهة MEDORA المصادق عليها حماية عملية للبيانات الحساسة داخل المتصفح وPWA. عند فقدان رؤية الصفحة، أو انتقال نافذة التطبيق إلى الخلفية، أو بدء الطباعة، تُخفى مساحة العمل مؤقتًا وتظهر رسالة حماية. تُعرض علامة مائية ديناميكية محدودة على الجلسة تتضمن MEDORA وهوية المستخدم ونطاق الفرع/الوضع، ولا تتضمن أرقام مبيعات أو بيانات مرضى أو حمولة Barcode.

يسجل الغلاف إشعارًا داخليًا محدودًا باسم `aldora:capture-risk` يتضمن سبب الإخفاء ووقت UTC فقط. هذا الحدث ليس بديلًا عن سجل تدقيق خادمي موثق، ولا تُرسل إطارات الكاميرا أو محتويات الشاشة إلى الخادم.

## حدود الويب وPWA

> لا يستطيع موقع ويب أو PWA منع نظام التشغيل أو جهازًا خارجيًا من تصوير الشاشة أو تسجيلها منعًا مطلقًا.

طبقة الويب تستطيع تقليل التعرض داخل الصفحة، الاستجابة لفقدان الرؤية أو بدء الطباعة، إخفاء المحتوى قبل/أثناء الحالة الخطرة، وتقديم علامة مائية قابلة للتتبع. لا ينبغي اعتبار `blur` أو `visibilitychange` آلية كشف مؤكدة لكل screenshot؛ بعض أنظمة التشغيل وأدوات الالتقاط لا ترسل إشارة يمكن للمتصفح قراءتها.

## المسارات الأصلية اللاحقة

| المنصة | أقصى حماية عملية | القيد المتبقي |
|---|---|---|
| Android أصلي | استخدام `FLAG_SECURE` للشاشات المنظمة، مع منع العرض في لقطات النظام حيث يدعم الجهاز ذلك | لا يمنع تصوير الشاشة بجهاز آخر، وقد تختلف سلوكيات الشركات المصنعة |
| iOS أصلي | مراقبة إشعارات التسجيل/الالتقاط وإخفاء المحتوى الحساس عند اكتشافها | لا يوفر iOS منعًا عامًا مضمونًا لكل screenshot داخل كل سياق |
| HarmonyOS أصلي | استخدام واجهات الخصوصية المتاحة في إصدار النظام مع إخفاء المحتوى عند إشعارات الالتقاط | التوافق يعتمد على نسخة HarmonyOS وواجهات التطبيق المتاحة |
| Web/PWA | إخفاء عند فقدان الرؤية، حماية الطباعة، watermark، ورسالة للمستخدم | لا يوجد تحكم كامل في نظام الالتقاط أو الأجهزة الخارجية |

## قواعد تشغيلية

يجب ألا تُعرض البيانات السريرية أو بيانات المرضى الكاملة في watermark أو رسائل الخطر. يجب أن يبقى إخفاء البيانات fail-safe: عند تعذر تحديد حالة الرؤية أو حدوث خطأ في دورة الحماية، تُحجب المساحة الحساسة بدل إبقائها مكشوفة. وتبقى صلاحيات المؤسسة والفرع والاختصاص والتحقق الخادمي هي مصدر القرار الأمني؛ طبقة الواجهة ليست بديلًا عن العزل أو التفويض.
